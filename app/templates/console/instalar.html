Na VPS nova, como root

1. Baixar os pacotes direto da gestão:

curl -fsS -o /root/portal-codigo.tar.gz "{{ res.codigo }}"
curl -fsS -o /root/segredos-no.tar.gz.enc "{{ res.segredos }}"

2. Extrair o código e rodar o instalador (ele encontra o pacote de segredos e pede a senha do pacote):

mkdir -p /opt && tar -xzf /root/portal-codigo.tar.gz -C /opt && cd /opt/portal_web && bash deploy/no/instalar.sh

3. No fim, apague o pacote de segredos:

rm /root/segredos-no.tar.gz.enc
