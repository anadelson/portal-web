Como usar a API

GET https://{{ orgao.dominio }}/dados/<base>.json — devolve JSON com fontes, base_legal, atualizado_em, total_registros, totais, campos e registros (até 50.000 por resposta).

Parâmetros opcionais (os mesmos filtros das telas): ano, mes (1 a 12; em receitas, 0 = acumulado), unidade, credor, q (texto). Exemplo: /dados/empenhos.json?ano={{ hoje.year }}&mes=3&credor=posto

CSV: /transparencia/<base>.csv com os mesmos parâmetros (UTF-8, vírgula como separador, ponto decimal). Atualização: a cada hora, das 7h às 19h, para o sistema contábil; a cada 6 horas para o PNCP; diária para o Siconfi.

LGPD: nenhuma base contém CPF. Pessoas físicas aparecem sem documento; servidores, só com nome, cargo, vínculo, lotação e remuneração bruta.
